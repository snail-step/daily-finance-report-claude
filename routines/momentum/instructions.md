# Taiwan Momentum Tracking — 獨立每日動能報告

## Scope and separation
只用價格、成交量及固定業務分類觀察動能，不搜尋新聞、財報、法人或用它們調整訊號。
本檔與 routines/brief/instructions.md 完全獨立；不得把原新聞報告的 36 檔標的、新聞窗口、情緒或 UP/FLAT/DOWN 規則套用至本報告。
所有路徑相對 repo 根目錄。輸出 reports/YYYY-MM-DD-momentum.md，YYYY-MM-DD 是台灣執行日期。所有說明使用繁體中文；保留英文代號與公式。
排程沿用週一至週五台灣 08:00。行情一律使用最新已完成的台股交易日 D；08:00 通常是前一交易日，不使用當日盤中 K 棒。
排程維護規則：日後調整 Codex 排程中與本報告相關的時間、標的、計算、輸出、驗證或 Git 流程時，必須同步更新本檔，讓排程設定與本檔一致。這是維護要求，非每日產報步驟。
明確列出執行時間、資料日期 D、前一交易日 D-1、來源及還原方式。休市時仍可產生當日報告，但註明「休市沿用，無新交易日」，不得把同一份資料說成新增訊號。

## Data acquisition and quality
1. 使用可用的 FMP 歷史行情；不可用時改用 TWSE／TPEx 或可信歷史行情服務（例如 Yahoo Finance）。批次平行取得去重後全名單及加權指數 ^TWII 至少 260 個交易日的日 OHLCV（不足時取得全部）。所有標的目前為上市，統一比較 ^TWII；若發現不符須標明並通知，不可自行替換標的。
2. 固定資料截止 D，不因某股缺資料而把它的舊日期當 D。依交易所行事曆核對假日；停牌／缺值不可補零、前向填值或壓縮成較短交易日窗口。
3. 記錄原始 OHLCV、來源 URL、擷取時間、幣別、股數／張數單位、公司行動及調整口徑。可將中間資料保存於暫存目錄，不自動提交巨大原始資料。
4. 使用一致的分割及除權息還原價格計算均線、報酬與新高；高價與收盤價必須使用同一調整因子。指數使用同日期的價格指數報酬，說明股票還原報酬與指數的口徑差異。成交量至少要處理股票分割，不能直接套現金股息調整因子。
5. 若無法確認還原口徑、公司行動、成交量單位或歷史序列，相關指標標 data gap，不可由搜尋摘要、單筆現價或圖片猜歷史數據。已知且有日期的過期值標 stale。上市未滿所需天數，標「歷史不足」而非判為弱勢。
6. 量價異常、零成交、最高價小於最低價或重複日期須檢查；失敗後每來源最多一次重試、一次備援。來源間有重大衝突時保留缺口，不選較符合敘事的數字。
7. 計算必須用程式處理時間序列，不讓文字模型心算。保留足夠歷史以用同一套規則重算 D 與 D-1。

## Deterministic metrics
以下 C/H/V 為一致還原口徑之收盤／最高／成交量；n 表示交易日數；所有窗口按交易日曆對齊。
- Rn = (C_D / C_(D-n) - 1) * 100，n=1,5,20。
- RSn = 個股 Rn - ^TWII 同期 Rn，n=5,20，單位為百分點；不是 RSI。
- MA20/MA60 = 截至 D 含當日最近 20/60 日收盤均值。
- 均線向上 = MA_n(D) > MA_n(D-5)；相等為平，下跌為下。
- RVOL20 = V_D / 前20交易日平均量（排除 D）。分母零則 data gap。
- H120 = D 前120交易日還原最高價的最大值（排除 D）。
- 收盤突破 = C_D > H120；盤中觸及不是收盤突破。
- 距前高 = (C_D/H120-1)*100%；正值標「已突破 +x%」。
- 月線乖離 = (C_D/MA20-1)*100%。
- 強勢股 = C_D>MA20 且 C_D>MA60 且 RS5>0 且 RS20>0。
- 個股四項分數 Q：C>MA20、C>MA60、RS5>0、RS20>0 各1分。僅用於透明呈現狀態及日變化，不當作投資報酬預測。
- 前一日同樣重新計算以上指標；首次報告也能計算昨日狀態。歷史不足不得寫「新轉強」。

## Individual and block states
個股按以下先後順序、同一規則計算 D 和 D-1：
1. 必要資料不足 → ⚪ 資料不足。
2. Q=4 且 MA20/MA60 都向上 → 🟢 強勢延續。
3. C<MA20 且 RS5<0 且（C<MA60 或 MA20向下）→ 🔴 動能偏弱。
4. Q(D)>Q(D-1) 且 C>MA20 且 RS5>0 → 🟠 開始轉強。
5. 其他 → 🟡 整理。
動能偏弱是狀態；只有從較佳狀態變弱才能寫「轉弱」。訊號不構成買賣指示。

區塊按以下順序：
- S08/S13 永遠不給區塊燈號，顯示「個股觀察（不給燈號）」。
- 固定成員任一缺必要資料 → ⚪ 資料不足，列有效數/固定總數，不把缺值當跌或更改分母。
- 完整樣本 >=2：強勢股 >= ceil(2N/3) → 🟢 強勢；偏弱股 >= ceil(2N/3) → 🔴 偏弱。
- 否則若組內 Q 均值較 D-1 上升且 RS5 中位數>0 → 🟠 改善中；其他 → 🟡 整理／分歧（同時有強勢與偏弱時寫分歧）。
- 較昨日 ↑/→/↓ 按組內 Q 均值變化判定。標示「小樣本」；有△成員標「代表性有限」。
- 顯示站上 MA20、MA60、強勢及收盤突破120日高點各 k/N，以及 R5、RS5、RS20 的組內中位數。
- 區塊動能總覽及逐區塊量價說明，嚴格依上方固定名單的產業分類順序排列：S01→S13、S15→S24、P01→P04。強弱、Q 均值、RS5 或資料不足都不能改變列序。不以主看股權重放大區塊。

## Report structure (plain Markdown only)
# 台股動能日報 — YYYY-MM-DD
執行時間、資料日、比較日、行情來源與調整口徑；休市沿用註記。

## 今日動能摘要
最多三點：最強、改善、轉弱。沒有符合者寫「無」，不可硬選。

## 區塊動能總覽
| 區塊 | 主看 | 狀態 | 較前一交易日 | 強勢 k/N | 月線上 k/N | 季線上 k/N | 新高 k/N | 5日RS中位數 | 限制 |
完整顯示全部27個分類，包括 S08、S13 兩個不給燈號者；列序須與固定名單一致。每個有效區塊附一句量價依據與領先／落後股；不加入新聞因果敘事。

## 個股明細
| 標的 | 所屬分類 IDs／主看或驗證 | 狀態 | 收盤／日期 | 1日% | 5日% | 20日% | RS5百分點 | RS20百分點 | RVOL20 | 距120日前高% | 月線／季線方向 | 月線乖離% |
每個去重股票一列；嚴格依固定名單的首次出現順序列出，不能依股票代號數字大小排序，也不能只報強勢股；缺口明確標 data gap/stale/歷史不足。

## 今日新增變化
新突破：D突破且D-1未突破；連續突破另標。
狀態改善／惡化：列 D-1 → D；Q變化用於相同狀態時說明。
跌回突破價：以最近20交易日最近一次「新突破」事件的固定門檻，判斷 D-1>=該門檻且D<該門檻；不要用每天移動的H120當原突破價。
新突破、連續突破、跌回突破價各清單，以及「狀態與 Q 變化」逐項內容，分別依`個股明細`相同的首次出現順序排列。只篩出符合條件的股票，保留原排序；同一清單內同股不得重複。
沒有新交易日不產生新增變化。

## 資料品質與方法
來源直接URL、擷取時間、價格及成交量還原口徑、缺口、樣本限制。首次執行的昨日數值為重算而非既有報告。
聲明這是固定上市股樣本動能，不代表全市場族群廣度；材料、設計、封測等業務差異不可抹除。

## Validation and Git
- 檢查27分類齊全且順序與固定名單一致、去重後所有代號一列、`個股明細`與`今日新增變化`均符合固定名單首次出現順序、所有驗證股均納入、指數日期一致、120日前高排除今日、所有分母固定、比較日正確、無新聞訊號混入。
- 不編造資料或用 data gap 掩蓋未嘗試取數。個別缺口可發布並通知；若全體行情或基準不可用，停止本報告並通知，不提交空殼。
- 僅在乾淨專用 main checkout、git fetch origin main 且可安全 fast-forward 後工作；禁止覆蓋無關變更。
- 若當日 momentum.md 已存在，保持原檔，只跳過動能報告，不能跳過另一份晨報。
- 使用既有 snail-step Git 身分；只提交當天新增的 momentum 報告，訊息 Add Taiwan Momentum Report for YYYY-MM-DD，普通 git push origin main 並驗證遠端。禁止 force push、PR、Issue、gh、GitHub API。
- 由雙報告排程呼叫時，排程負責共用Git前置檢查；每份報告依序提交推送，另一份已完成不應阻止本份執行。若Git衝突或推送失敗，停止後續Git操作並通知。
